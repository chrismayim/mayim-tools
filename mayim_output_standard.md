For the file outputs, can we configure it as follows:

The user selects (checkbox) which outputs he requires.
The user then selects an output folder for raster outputs, an output folder for shp outputs, one for CSV outputs, and one for WORD outputs. All outputs selected are then generated and saved in the corresponding folder.
The user provides an optional project number. The file name is then constructed as PROJECT NAME_layer description. Use underscores throughout instead of spaces.
