# Mayim Tools - Python packages
#
# QGIS 4 for Windows already includes numpy, pandas, scipy, matplotlib,
# shapely and GDAL. Install the others in the OSGeo4W Shell (close QGIS
# first):
#
#     python -m pip install -r requirements.txt
#
# A tool whose package is missing is listed in the Processing Toolbox as
# "<tool> (unavailable)", and its help names the package to install. The
# other tools work without it.
#
# Package              Needed by
python-docx            # Word reports (most tools)
geopandas              # Design Rainfall Estimation (South Africa)
h5py                   # Import RAS 2D data (optional: QGIS's GDAL reads the file when h5py cannot load)
xarray                 # GRIB to CSV, NetCDF4 tools, ERA5, IMERG, MERRA2
cfgrib                 # GRIB to CSV (reads GRIB files through xarray)
netCDF4                # NetCDF4 tools, IMERG
h5netcdf               # IMERG
requests               # CHIRPS, CMORPH, ERA5, IMERG, MERRA2, PERSIANN
cdsapi                 # Extract: ERA5 precipitation
earthaccess            # Extract: IMERG and MERRA2 precipitation
rasterio               # Extract: CHIRPS precipitation
hecdss                 # Prepare HEC-HMS project (DSS output, optional)
swmm-toolkit           # Prepare SWMM project (optional test run)
