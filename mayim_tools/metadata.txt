about=Mayim Tools is a QGIS Processing plugin developed by Mayim Consulting, providing a suite of hydrology, rainfall and data processing tools. Rainfall Tools group: Design Rainfall Estimation (South Africa); point extraction of CHIRPS, IMERG, MERRA-2 and CMORPH precipitation records; Precipitation data to DDF (rainfall frequency analysis); Precipitation data to Huff Curves; and DDF to Alternating Block Design Hyetographs. Data Tools group: GRIB to CSV conversion; NetCDF4 to CSV conversion (flatten or point extraction, for an arbitrary user-supplied NetCDF4 file) and its companion List NetCDF4 Variables discovery tool. Rainfall Tools group also includes Design Storm Ensembles, which builds Huff/ARR-style representative temporal storm pattern ensembles for 24 design durations and three AEP bands from a sub-daily rainfall record and a DDF table. Hydrological Tools group also includes D8 Flow Accumulation (WBT), an exact replication of WhiteboxTools' own D8FlowAccumulation tool that consumes either a raw DEM or this suite's own D8 Flow Direction plugin's pointer output directly. Rainfall Tools group also includes Extract: ERA5 precipitation, which reads ERA5/ERA5-Land total precipitation directly from the Copernicus Climate Data Store (CDS), for a point or point layer, over the full 1950-present record or a specified date range. v0.5.0 adds a second, selectable "Fast" access method using a separate, purpose-built CDS timeseries dataset - confirmed by live testing to retrieve the full 76-year record in around 40 seconds (versus multi-hour Standard-method runs) and to match the CDS website exactly; offered as an opt-in alternative, not the default, since ECMWF's own documentation labels that dataset experimental and not recommended for operational use. Hydrological Tools group also includes Catchment Delineation, which takes a D8 pointer and its DEM with pour points (snapped to flow accumulation) or pour lines and writes repaired catchment polygons (total or incremental), a catchment DEM, longest flow paths and a parameters report (area, shape, slopes, hypsometry, drainage density, and Kirpich, USBR/SANRAL and Bransby-Williams time of concentration). v0.2.0 adds geomorphometric parameters (Strahler stream order, bifurcation ratio, Melton ratio, relief ratio and more) and an optional Word (.docx) annexure report with parameter definitions, figures, a guideline-neutral catchment description and modelling considerations. v0.3.0 adds optional stream network (links split at junctions, with Strahler order, upstream area, slope and downstream link) and catchment centroid vector outputs. Rainfall Tools group also includes Adjust Sub-daily Rainfall to DDF, which adjusts a sub-daily gridded rainfall series (ERA5, IMERG, CMORPH...) so that its annual maxima at every tested duration match a reference gauge-based DDF while keeping the recorded storm timing (anchor-duration magnitude mapping plus mass-preserving nested peak-window scaling, with held-out validation durations, bootstrap intervals and an optional stochastic ensemble), and writes the adjusted series, a Word report and an optional storm library for Monte Carlo design storms. v0.2.0 adds a new HEC-RAS Tools group: Import RAS 2D data, ported from the standalone "Import RAS 2D Data" plugin, reads a finished HEC-RAS 6.x/7.0 2D-domain model's geometry - mesh (perimeter, cells, breaklines, refinement regions), SA/2D connections (bridges, weirs, culverts, linear routing), pump stations, boundary condition lines, initial condition points, reference lines/points/areas, and pipe networks - directly from its HDF5 file with h5py (no ras-commander dependency) into styled GeoPackage layers, one per selected element, in one tool run. Hydrological Tools group also includes DEM depression stage-storage, which reads stage-storage (elevation-area-volume) curves for ponds, dams, detention basins and natural depressions straight off a DEM inside storage-area polygons - fractional edge-cell coverage, connected-pool or level-pool counting, automatic spill level (with a per-feature or global maximum-stage override) - and writes a stage table CSV, a HEC-RAS / HEC-HMS elevation-volume table, water-surface polygons, a depth raster, spill points and an optional Word report with stage-storage, stage-area, depth-area and depth-volume curves. It fails with a clear message, rather than writing empty layers, when no polygon encloses a depression. Hydrological Tools group also includes Stream Network, which extracts the stream network from a D8 pointer and DEM (whole raster or upstream of pour points) and classifies every reach by Strahler, Shreve, Horton and Hack ordering in one line layer, with channel heads/confluences/outlets, main stems, a constant-drop test for the stream threshold, Horton ratios, reach routing inputs (velocity, travel time, Muskingum K and X), a sectioned CSV and an optional Word report. Catchment Delineation v0.4.0 writes the same stream network outputs as the Stream Network tool (reach layer with Strahler, Shreve, Horton and Hack orders and routing inputs, nodes, main stems, sectioned CSV and optional stream network Word report) for the network upstream of its outlets. Soil Tools group (new): Extract: SoilGrids 2.0, which reads ISRIC SoilGrids 2.0 soil properties (sand, silt, clay, organic carbon, bulk density, coarse fragments, pH, CEC; optional water content and SoilGrids 2017 depth to bedrock) at 250 m for six depths, for an area (multi-band GeoTIFFs) or points (CSV), with the 5/50/95% prediction quantiles and a metadata log of sources, units, quality checks and uncertainty.
