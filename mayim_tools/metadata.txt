about=Mayim Tools is a QGIS Processing plugin developed by Mayim Consulting, providing a suite of hydrology, rainfall and data processing tools. Rainfall Tools group: Design Rainfall Estimation (South Africa); point extraction of CHIRPS, IMERG, MERRA-2 and CMORPH precipitation records; Precipitation data to DDF (rainfall frequency analysis); Precipitation data to Huff Curves; and DDF to Alternating Block Design Hyetographs. Data Tools group: GRIB to CSV conversion; NetCDF4 to CSV conversion (flatten or point extraction, for an arbitrary user-supplied NetCDF4 file) and its companion List NetCDF4 Variables discovery tool. Rainfall Tools group also includes Design Storm Ensembles, which builds Huff/ARR-style representative temporal storm pattern ensembles for 24 design durations and three AEP bands from a sub-daily rainfall record and a DDF table. Hydrological Tools group also includes D8 Flow Accumulation (WBT), an exact replication of WhiteboxTools' own D8FlowAccumulation tool that consumes either a raw DEM or this suite's own D8 Flow Direction plugin's pointer output directly. Rainfall Tools group also includes Extract: ERA5 precipitation, which reads ERA5/ERA5-Land total precipitation directly from the Copernicus Climate Data Store (CDS), for a point or point layer, over the full 1950-present record or a specified date range.
